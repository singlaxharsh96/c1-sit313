# P4 checklist

- [ ] Enable Email/Password in Firebase Authentication.
- [ ] Publish `firestore.rules` in the Firestore Rules tab.
- [ ] Run `npm install` and `npm run dev`.
- [ ] Register with a full name, valid email, and matching password fields.
- [ ] Confirm the account appears under Authentication > Users.
- [ ] Confirm a profile appears under Firestore > Data > users.
- [ ] Test correct and incorrect login details.
- [ ] Check that the Navbar and Footer appear on Home, Login and Sign-up.
- [ ] Keep `.env` and `node_modules/` out of Git.
- [ ] Commit project files with meaningful comments.
- [ ] Prepare screenshots, a 2–4 minute walkthrough video, and the short report requested in the task sheet.
